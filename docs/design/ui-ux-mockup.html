怎麼依資料設計

  • 每張圖都來自 config 的 charts：count 變成頂部數字，over-time 是每週柱狀圖，by-category 是分佈，histogram 是金額分佈
  • 分類少（≤5，例如 Region、Format）用一條比例條加圖例看佔比；分類多（Round、Sector、City）用排名橫條，前 6 名加 Show all
  • 每張圖都有 Chart / Table 切換，保留原本的無障礙資料表
  • 點任一長條或分佈列，會帶著那個條件跳到表格

真實資料看出的事

  • Fundraising 的週柱狀圖是過去式，標出本週與最高峰；Hackathons 是未來式，加上 Today 線，之後的週用淡色
  • Hackathons 只有 16% 寫了獎金，所以 Prize pool 圖上方直接標出覆蓋率，避免誤讀
  • 每張圖的副標說一句重點，例如「Top 3 make up 58% of rounds」

表格與紀錄頁

  • 篩選欄依 config 欄位自動產生：enum、tags 用勾選，日期與金額用 pill
  • 表格欄位就是 config 的 table.columns，第一欄固定、其餘可橫向捲動
  • 紀錄頁的引用、來源、歷史都是真實資料；Smart filter 仍是關鍵字規則
